# Control Baseline Selection

## Baseline Determination

In accordance with the Moderate security categorization determined under FIPS 199, the Moderate baseline of security controls defined in NIST SP 800-53 Rev 5 was selected for the Human Resources Information System (HRIS).

The Moderate baseline is appropriate due to the system’s processing of employee personally identifiable information, payroll data, and other sensitive administrative records.

---

## Tailoring Considerations

Control tailoring was performed in accordance with organizational policy and system-specific risk considerations.

Tailoring activities included:

- Identification of controls inherited from enterprise common control providers  
- Classification of controls as common, hybrid, or system-specific  
- Review of control applicability based on SaaS architecture  
- Alignment with the shared responsibility model between the organization and the SaaS provider  

---

## Control Responsibility Model

Due to the system’s SaaS architecture, control implementation responsibilities are distributed as follows:

- Common Controls: Enterprise-level policies and procedures inherited by the system  
- Hybrid Controls: Controls requiring both enterprise-level governance and system-specific implementation  
- System-Specific Controls: Controls fully implemented within the HRIS tenant environment  

This responsibility model reflects the organization’s governance framework and shared responsibility considerations with the SaaS provider.
