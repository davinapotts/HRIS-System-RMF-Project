# Control Assessment Approach

The HRIS Moderate baseline controls would be assessed in accordance with NIST SP 800-53A assessment procedures. Assessment activities would include examination of documentation, interviews with responsible personnel, and technical testing where applicable.  

This repository documents the approach that would be used to assess selected representative controls within the system.

---

## Assessment Roles

The following roles would participate in the assessment process:

- Security Control Assessor (SCA)
- HRIS System Owner
- Enterprise Identity Services Manager
- SaaS Vendor Security Representative
- Chief Information Security Officer (CISO)

The Security Control Assessor is responsible for independently evaluating control implementation effectiveness and documenting findings.

---

## Assessment Methods

Control assessments would follow the three primary methods defined in NIST guidance:

- **Examine** – Review of policies, procedures, configuration settings, system documentation, and system artifacts.
- **Interview** – Discussions with responsible personnel to validate implementation practices and operational procedures.
- **Test** – Technical validation of system configurations, access restrictions, logging mechanisms, and security controls where applicable.

---

## Sample Evidence by Control

### AC-1 Access Control Policy and Procedures

- Approved Access Control Policy
- Annual policy review documentation
- Change management records reflecting policy updates

### AC-2 Account Management

- User provisioning and deprovisioning requests
- Access approval documentation
- Quarterly account review reports
- Account disablement records following employee separation

### AC-6 Least Privilege

- Role-based access control matrix
- Privileged account listings
- Access review validation records
- Administrative activity logs

---

## Documentation of Findings

Assessment results would be documented in a formal Security Assessment Report (SAR). Identified weaknesses or deficiencies would be entered into a Plan of Action and Milestones (POA&M) for remediation tracking.

Findings would include:

- Control identifier
- Description of weakness
- Risk impact statement
- Recommended corrective action
- Target remediation date
- Responsible party

---

## Assessment Frequency

Control assessments would occur:

- Prior to authorization decision
- Annually as part of continuous monitoring
- Following significant system changes
- Upon identification of security incidents impacting control effectiveness

---

This assessment approach reflects standard RMF lifecycle practices and demonstrates how control effectiveness would be evaluated within a Moderate impact SaaS HRIS environment.
